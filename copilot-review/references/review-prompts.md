# Copilot Review Prompts Reference

## コードレビュー用プロンプトテンプレート

### 標準コードレビュー
```
以下の観点でコードをレビューしてください:
1. バグの可能性がある箇所
2. セキュリティの問題
3. パフォーマンスの問題
4. コードの可読性・保守性
5. ベストプラクティスへの準拠

各指摘に以下の重要度を付けてください:
- CRITICAL: 即座に修正が必要（バグ、セキュリティ、データ損失）
- WARNING: 修正を推奨（パフォーマンス、保守性の問題）
- INFO: 改善提案（スタイル、可読性）

出力フォーマット:
## [CRITICAL/WARNING/INFO] 指摘タイトル
- ファイル: path/to/file:行番号
- 問題: 具体的な問題の説明
- 提案: 修正方法の提案
```

### セキュリティ重視レビュー
```
セキュリティの観点から集中的にレビューしてください:
- SQLインジェクション
- XSS（クロスサイトスクリプティング）
- CSRF
- 認証・認可の不備
- 機密情報のハードコード
- 入力値の検証不足
```

### パフォーマンスレビュー
```
パフォーマンスの観点から集中的にレビューしてください:
- N+1クエリ
- 不要なループ処理
- メモリリーク
- キャッシュの未利用
- インデックスの不足
```

## プランレビュー用プロンプトテンプレート

### 設計レビュー
```
以下の設計プランをレビューしてください:
1. アーキテクチャの妥当性
2. スケーラビリティ
3. 依存関係の適切さ
4. エラーハンドリングの考慮
5. テスト容易性
6. 既存コードとの整合性

リスクと見落としがあれば指摘してください。
```

### 実装プランレビュー
```
以下の実装プランをレビューしてください:
1. 手順の妥当性と完全性
2. 各ステップのリスク
3. ロールバック可能性
4. テスト計画の十分性
5. 影響範囲の特定

見落としている手順やリスクがあれば指摘してください。
```

## フォローアップレビュー用プロンプト

### 修正確認
```
前回のレビューで指摘した以下の問題について、修正内容を確認してください:
{指摘リスト}

修正が適切か、新たな問題が発生していないかを確認してください。
```
